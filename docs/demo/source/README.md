# Video and audit report sources

Everything needed to rebuild the silent walkthrough (`docs/demo/demo.mp4`) and the audit report
(`docs/demo/AUDIT_REPORT.*`) from this repository alone. Paths below are relative to the repo root.

## What is here

| Path | What it is |
|---|---|
| `index.html` | Root of the video: theme (colours, type), and the timing of every slide |
| `compositions/bg.html`, `compositions/chrome.html` | Background grid, and the persistent project label, slide counter and progress bar |
| `compositions/s01-context.html` | Slide 01, the industry and four everyday problems |
| `compositions/s02-hook.html` | Slide 02, the project in one sentence |
| `compositions/explainer.html` | Slides 03-04, the white "how it works" chapter (edit its `CONFIG` block) |
| `compositions/s03-architecture.html` | Slide 05, the layered architecture diagram (nodes + the `W` wires array) |
| `compositions/s04-routes.html` | Slide 06, the ADI / CV² scatter and one SKU through six origins (data injected by `tools/inject_sheet.py --block RUN`) |
| `compositions/value.html` | Slide 07, the 8-week forecast sheet and planner scene (data injected by `tools/inject_sheet.py --block SHEET`) |
| `compositions/s05-results.html`, `s06-twist.html`, `s07-end.html` | Slides 08-10, results, what didn't win, end card |
| `assets/forecast_sheet.json` | Exported by `tools/export_forecast_sheet.py` from the repo's own functions and `outputs/forecasts.parquet` |
| `assets/scatter-end.png` | End-card background, `outputs/sku_segments.csv` drawn by `tools/make_end_scatter.py` |
| `audit/facts.yaml` | Every figure (F-xx), assumption (A-xx), slide text and check expression used by the report |
| `tools/build_audit_report.py` | Builds the slide stills, re-checks every figure against the repo outputs, writes MD, DOCX and PDF |
| `tools/export_forecast_sheet.py` | Exports the last-origin forecast sheet, the scatter and the example SKU as JSON |
| `tools/inject_sheet.py` | Inlines that JSON into a composition (renders cannot fetch files) |
| `tools/make_end_scatter.py` | Draws the end-card scatter |
| `package.json`, `hyperframes.json`, `meta.json` | HyperFrames project files (CLI pinned to 0.8.156) |

Fonts (Inter, JetBrains Mono, Montserrat) are referenced by name and embedded by the HyperFrames
renderer; all three are SIL Open Font License.

## Requirements

- Node 22 and `npx` (HyperFrames 0.8.156 is fetched by `npx`), plus Chrome/Chromium for rendering.
- `ffmpeg` for compressing the video and extracting slide stills.
- LibreOffice (`soffice`) to convert the report to PDF.
- The repo's own environment (`uv sync`) for `make run` and `export_forecast_sheet.py`.
- For `build_audit_report.py`, `inject_sheet.py` and `make_end_scatter.py` (any Python 3.11+, not added to
  the repo's `pyproject.toml`): `pip install pyyaml pandas pyarrow python-docx pillow numpy matplotlib`.

## Rebuild the numbers, the video and the report

```bash
# 1. repo outputs (about 12 minutes)
make run

# 2. inputs for the video
PYTHONPATH=src .venv/bin/python docs/demo/source/tools/export_forecast_sheet.py docs/demo/source/assets/forecast_sheet.json
python3 docs/demo/source/tools/inject_sheet.py docs/demo/source/assets/forecast_sheet.json \
  docs/demo/source/compositions/value.html --block SHEET \
  --keys origin_week,window_end_week,skus,model,wape_8wk_all,forecast_units_8wk,sold_units_8wk,rows
python3 docs/demo/source/tools/inject_sheet.py docs/demo/source/assets/forecast_sheet.json \
  docs/demo/source/compositions/s04-routes.html --block RUN \
  --keys scatter,example,forecast_rows_total,forecast_models
python3 docs/demo/source/tools/make_end_scatter.py outputs/sku_segments.csv docs/demo/source/assets/scatter-end.png

# 3. render (90.4 s, 1920x1080, 30 fps, silent) and compress
cd docs/demo/source
npx --yes hyperframes@0.8.156 check
npx --yes hyperframes@0.8.156 render -f 30 -q looks -o renders/intermittent-demand-forecasting-master.mp4
cd -
ffmpeg -y -i docs/demo/source/renders/intermittent-demand-forecasting-master.mp4 -c:v libx264 -preset slow -crf 25 \
  -pix_fmt yuv420p -movflags +faststart -an docs/demo/demo.mp4

# 4. audit report: slide stills, automated checks, AUDIT_REPORT.md/.docx/.pdf
python3 docs/demo/source/tools/build_audit_report.py docs/demo/source/audit/facts.yaml
```

`build_audit_report.py` exits with code 1 if any figure on screen no longer matches the repo outputs.
LightGBM runs on 4 threads and the data is regenerated by `make run`, so check the report after a
fresh run; the change-impact matrix lists which figures and slides each assumption affects.

The `renders/` folder (about 15 MB) is not committed; step 3 recreates it.
